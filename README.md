# ANGEL STUDIO
> *"Create beyond the original."*

Angel Studio is an **AI Creative Director** — it looks at your visual design, tells you what it's actually saying visually, and shows you what it could become.

---

## The Three Core Experiences

### 1. ✦ Visual DNA
- Deep color palette extraction with harmonic roles
- Aesthetic Archetype identification (*Haute Editorial*, *Cyber-Minimalism*, *Swiss Brutalism*, *Organic Editorial*)
- Mood & emotional tone keywords
- Typography personality & visual density assessment
- Natural-language **Creative Director interpretation**

### 2. ✦ Explore Directions
- 4 to 6 divergent creative evolution branches (*Cinematic Noir*, *Haute Horlogerie*, *Quantum Hologram*, *Swiss Brutalism*)
- Palette shifts and typography recommendations
- Side-by-side evolution comparison modal with prototype previews

### 3. ✦ Angel Critique & Interactive Coordinate Pins
- Honest evaluation across 6 fundamental pillars: *Visual Hierarchy*, *Contrast*, *Composition*, *Negative Space*, *Readability*, and *Focal Point*
- Numbered issue cards with detailed observations and actionable recommendations
- **Interactive canvas pins** dynamically plotted directly over the visual image coordinates `(x%, y%)`
- Hover a critique item to highlight the focal box on the canvas

---

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev
```

Visit `http://localhost:3000` in your browser.
